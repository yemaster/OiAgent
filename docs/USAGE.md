# OiAgent 使用手册

[返回项目首页](../README.md)

本地 Agent 一体化桌面工作区。Tauri 2 + React + TypeScript + shadcn/ui，使用系统 WebView，不捆绑 Chromium。界面为图标工具栏、分区侧栏和主工作区，采用中性灰白主题与系统字体。

## 启动

需要 Node.js 22+、Rust，以及 Tauri 对应系统的构建依赖。当前已在本机 macOS 完成构建。

```sh
npm install
npm run desktop
```

生产打包：

```sh
npm run desktop:build
```

macOS 应用位于 `src-tauri/target/release/bundle/macos/OiAgent.app`。当前为本机未公证构建，不是已签名发行版。可直接通过 Finder 打开。

仅看界面：

```sh
npm run dev
```

访问 `http://127.0.0.1:1420`。浏览器模式明确标记“演示数据”，不会访问本机历史、启动程序或调用 LLM。桌面版启动后使用真实本机数据，不加载演示任务。启动时先显示保存的任务和历史索引，后台并行检测内置 Agent 版本并同步历史；解析进度保存在本机，下次启动只解析新增或变化的记录。首次建立索引仍需要时间，但不会阻塞工作区。

## 界面入口

- **工作台**：当前任务、历史记录、用量统计。侧栏项目按最近使用排序并跨启动记忆；没有使用记录的项目按最近任务时间排序。等待操作的任务优先显示。
- **TODO List**：记录未完成和已完成的计划，按项目搜索、标记重要；将计划内容填入新建任务。
- **自动化**：超级 Agent 的自动派发。先连接 LLM API，再填写最终目标。
- **项目文件**：进入项目或任务后，侧栏切换“文件 / 改动”。按目录展开、搜索文件；点击文件在新 tab 中用 Monaco 编辑，`⌘/Ctrl+S` 保存。Git 改动以只读差异展示，可切换左右/统一视图。
- **Agent 程序**：显示已安装程序，未安装的收起；Claude Code API 配置为独立侧栏页面，Claude Code 卡片提供直达入口。
- **插件**：独立管理命令型扩展。
- **设置偏好**：通过侧栏切换通用设置、界面设置、LLM API、局域网连接、关于等独立页面；API 草稿在切换时保留，新建任务可直达 LLM API 并返回草稿。左侧图标提示统一向右展开。
- **使用指南**：首次启动显示三个可操作步骤，也可从左下角帮助按钮重新打开。首次打开即记录为已展示，之后启动直接进入“当前任务”，无需先完成指南。

“新建任务”默认使用 Agent 对话；右上“运行方式”可切换自定义命令或交互终端。“更多设置”包含任务名称、模型、额外启动参数（每行一个参数）和环境变量（每行 `NAME=value`）。从管理程序返回保留新建任务草稿。

## 已实现

OiAgent 使用 O / i 融合的单色标志，已接入最左侧工作台入口、关于页、favicon 和桌面应用图标。透明标志与桌面图标源文件位于 `public/brand/`；运行 `npm run brand:icons` 可重新生成各平台尺寸。界面标志使用透明轮廓跟随主题文字色；桌面图标使用固定浅色底板。开发版通过 `npm run desktop` 重新编译启动；正式版通过 `npm run desktop:build` 生成带最新图标的应用包，再替换已安装版本。只执行前端构建、`cargo check` 或重启旧应用包不会更新原生应用图标。

- 自动发现 Codex、Claude Code、Qwen Code、Gemini CLI、OpenCode、Aider、Goose，支持 PATH、Homebrew、NVM 和常见用户安装目录。添加、编辑和移除自定义程序。
- 按项目目录组织任务；任务卡片显示状态、最新消息和已上报 Token。支持项目、Agent、状态、关键字筛选及卡片/列表切换。
- 聊天式任务详情：单列正文、连续执行记录分组、长消息展开、回到最新；子 Agent 与日志按需在详情面板查看。支持 Markdown、代码块、按调用 ID 配对的工具步骤（命令、文件、搜索、输出及错误）、原始日志、元数据、后续提示词、继续会话、重试、停止。
- 自动导入 Codex、Claude Code、Qwen Code 的 JSONL 历史及子 Agent 记录；父子会话可相互跳转，子会话独立计量，保留原始项目路径，增量读取追加记录，处理不完整末行、文件替换和截断。
- 历史搜索、重命名、归档、恢复、Markdown 导出。归档和重命名只改变 OiAgent 的索引，不改写原始历史文件。
- 新建任务的三种入口：内置 Agent、自定义启动命令 + Prompt、xterm.js + 系统 PTY 交互终端。可先保存为待启动任务。
- 统计任务/会话、输入、输出和缓存 Token，按项目和 Agent 汇总，支持时间筛选与 CSV 导出。原生会话累计用量按会话 ID 去重，子 Agent 使用独立标识避免被父会话合并。
- 工作流：编排本机 Agent、人工确认和 LLM 检查步骤，保存复用。支持结果接力、暂停继续、重启恢复和限次返工。
- 命令型插件：导入 JSON manifest 即可注册 Agent，复用任务执行、日志和历史系统。
- 全局搜索 `⌘/Ctrl+K`、新建任务 `⌘/Ctrl+N`、发送消息 `⌘/Ctrl+Enter`；支持减少动画的系统偏好。

Agent 能力与官方协议来源见 [支持范围](AGENT-SUPPORT.md)。新增四种 Agent 暂不导入它们已有的外部历史；在 OiAgent 中启动的任务均会保存记录。Aider、Goose 当前采用文本输出，未上报的用量显示“未上报”。

## TODO List

点击左侧清单图标进入。输入计划名称后按 Enter 添加；点击「添加详情」进入独立页面，填写备注、父计划和可选的项目目录。点击列表中的名称进入编辑页；返回列表保留未保存草稿与筛选状态，保存或放弃后返回原列表。勾选后移入「已完成」，取消勾选即可恢复。支持搜索、项目筛选和重要标记。可设置截止日期，或用「今天」「明天」快速填写；列表标出今天到期和逾期计划。同级未完成计划按截止日期排序，无日期的排在后面，日期相同则重要计划优先。

计划支持最多 5 层父子关系。在计划的「更多操作」中选择「添加子计划」，默认沿用父计划的项目目录。列表支持折叠，父计划显示直接子计划的完成数；搜索时保留父计划作为层级参照。编辑页可以更换父计划，选择「无（独立计划）」可移出原层级。

完成父计划会同时完成所有子计划，有未完成子计划时先确认；恢复子计划会恢复其上级计划。完成全部子计划不会自动完成父计划，仍由用户确认。删除父计划时保留子计划，并将其上移一级。

未完成计划右侧的「创建任务」会将名称、备注、截止日期和项目目录填入新建任务页；父计划还会附带未完成子计划及其备注，选择 Agent 后再启动。未指定目录时使用临时项目；已经清理的临时目录不会继续沿用。已有任务草稿时，可选择追加内容、替换草稿或取消。追加保留原草稿的项目和 Agent 设置。

填入任务、启动任务都不会自动完成计划，检查结果后自行勾选。计划保存在应用数据目录的 `todos.json`，重启后保留；浏览器预览使用独立的浏览器存储。保存失败时保留输入，检测到其他修改时要求刷新，避免覆盖。删除计划不删除已经创建的 Agent 任务。

## 文件编辑与改动

Monaco 与语言 Worker 本地打包、按需加载，不从 CDN 下载，也不把项目文件发送到远端。文本文件限 UTF-8、2 MB；符号链接、二进制和 Git 内部文件不进入编辑器。目录按需读取，默认收起隐藏文件及常见构建目录；查找文件支持项目内路径匹配。

文件和任务共用标签栏；切换对话保留未保存的文件内容，关闭脏文件可保存或放弃。当前打开文件每 4 秒检查磁盘版本，Agent 的外部修改在未编辑时自动刷新；有未保存内容时保留两份版本并打开差异合并，保存前再次核对版本。

对话里的文件编辑事件显示紧凑卡片，文件名可打开编辑器，“查看改动”打开工作区差异。支持 Claude 文件编辑、Codex 文件变更及多文件 patch；调用参数和输出仍默认收起。项目外文件保留记录，但不能从卡片越界打开。

“改动”是整个工作区相对 Git HEAD 的差异（含已暂存、未暂存、未跟踪文件），不是独占归因于某个 Agent。近期任务工具记录涉及的文件会标记“本任务记录涉及”，这也可能包含读取而非写入。没有 Git 时仍可编辑文件，但不伪造历史版本；不提供自动 Git 初始化、回滚或提交。

## 多标签、追加消息与 API 配置

任务以独立 tab 打开，保留对话滚动位置和未发送内容；标签显示 Agent 图标、标题和状态，关闭标签不停止任务。面包屑随当前标签显示项目和任务。执行分组和包含嵌套执行记录的上层默认展开；最低一级工具调用（包括命令、编辑、计划、派发子 Agent）默认收起，摘要保留状态，点击后查看内容并复制。

关闭当前标签返回最近访问且仍可用的标签或页面；例如从 Skills 列表打开编辑器，关闭后回到该列表，不会跳到更早打开的任务。MCP / Skills 和指令文件页面会保留 Agent、作用范围及所选分页。关闭后台标签不改变当前视图；取消关闭或保存失败时保留编辑器和草稿。任务、文件、项目和聊天消息提供对应右键菜单。标签支持关闭其他 / 右侧标签，未保存的文件逐个询问，取消会停止后续关闭。Monaco 保留编辑器菜单，终端鼠标仍交给 TUI；表单保留系统文本编辑菜单。聚焦操作项后也可用 Shift+F10 打开菜单。

侧栏在页面间保持相同宽度，拖动右边缘调整并记住；双击恢复 256 px，聚焦分隔线后可用左右键调整。左侧工具栏图标统一为 20 px，点击区域为 40 px。管理页面只呈现各自功能，点击“工作台”恢复之前的项目或标签。中间侧栏顶部只显示当前分区标题，不重复显示品牌名称。

任务运行中可追加消息或撤回待发送消息，成功结束本轮后依次执行。失败、停止或等待操作时暂停队列，可明确点击继续。追加是轮次队列，不是 CLI 运行中的即时 steering。

每条后续消息可选用不同的已安装 Agent；仍保存在同一个 OiAgent 任务。各 Agent / API 配置保留各自原生会话 ID，切换时传递原任务与最近最多 40 条、约 48,000 字符的对话和工具记录。不会把其他 Agent 的会话 ID、额外参数或环境变量直接移交。Aider、Goose、自定义程序通过文本上下文续接，不保证恢复原生会话内部状态。

在「Agent 程序 → Claude Code API 配置」维护多套 Base URL、密钥、默认模型以及 Haiku / Sonnet / Opus / Fable 映射。新建任务及每次追加消息均可选择配置。服务必须兼容 Anthropic Messages；OiAgent 不做 API 协议转换。密钥保存在系统凭据库；不写入任务元数据，不改写 Claude 全局配置。真实服务调用与系统凭据授权交互尚未实机验收。

添加和编辑 API 使用独立页面。点击「获取模型列表」可搜索服务返回的模型并填入默认模型或映射；接口不可用时继续手动输入。「测试连接」使用所选模型发送一条简短 Messages 请求，可能产生少量用量，列表页也提供入口。远程服务使用 HTTPS，本机 HTTP 可用；修改地址或鉴权方式后重新填写密钥，不会沿用原服务的密钥。测试不会修改已保存配置。

详情的「终端」模式使用真实 PTY，输入、滚动及鼠标由 xterm / 原生 CLI 处理。终端仅替换任务详情的对话区域，工具栏、侧栏和任务 tab 保留；加载失败局部显示错误，不清空整个工作区。无头任务不能直接附着为 TUI；操作会先停止当前进程，再在新 PTY 中恢复该 Agent 的原生会话。没有原生会话 ID 时打开新会话。终端运行期间请直接在终端输入，聊天消息队列暂不执行。PTY 输出保存在终端记录中。已绑定原生会话的 Codex / Claude / Qwen 终端会增量同步 JSONL 消息和工具事件到原任务；活动视图每秒读取，切换视图立即读取，实际延迟取决于 CLI 何时写入原生日志。同步保留其他 Agent 的已有对话，退出终端前收尾，后续 GUI 任务不会被重复导入。Claude 新建 TUI 使用明确的 session ID；其他无会话 ID 的终端和未接入原生历史格式的 Agent 暂不支持结构化同步。

高级环境变量仅在本次应用运行期间保存，重启后需重新配置；额外启动参数按独立 argv 传递，不解释 Shell 语法。

## 工作流与 LLM 设置

在“设置偏好”中填写 API Base URL（含服务商 API 前缀，例如 `https://provider.example/v1`）、模型 ID 和 API Key，然后保存。远程地址使用 HTTPS，本地模型允许 localhost HTTP。API 地址、模型和 API Key 使用 AES-256-GCM 加密保存在应用数据目录的 `secrets/llm.enc`，重启后自动读取，无需解锁系统钥匙串。随机加密密钥保存在同目录的 `llm.key`，备份时需要一并保留。相同 API 地址下留空 Key 会保留已存密钥，更换地址不携带旧密钥；可在设置中移除整份配置。保存失败时保留原配置，密钥不写入 localStorage 或任务数据。

旧版本的 LLM 钥匙串记录不会自动读取，更新后需重新填写并保存一次 API Key；旧记录保持原样。Claude Code API 和局域网配对仍使用系统凭据库。

「自动化」分为工作流库和运行记录。新建工作流在独立页面编辑，可从示例开始，或填写目标后用 LLM 生成计划；生成不会自动执行。每一步可选择 Agent 任务、人工确认或 LLM 检查，支持调整顺序，按步骤选择 Agent、权限、模型及 Claude Code API。

启动后保存独立计划快照，步骤共享项目并依次执行；后一步收到前序结果摘要及用户补充。人工确认会暂停等待，LLM 检查可在失败时让紧邻的上一步 Agent 返工 1–2 次，超限后暂停。每个工作流支持 1–24 步，Agent 步骤默认不设执行时限，直到程序结束或手动停止；可在高级设置中选填执行时限（分钟），留空不限制。旧版默认的 30 分钟不会自动启用。每步最多执行 10 次。

运行详情显示步骤状态、结果和尝试记录。暂停在当前步骤结束后生效，停止会取消当前子任务；重启后保留完成进度，等待用户继续，不自动重放未确认的操作。失败步骤可重试，已有文件修改不回滚。复制运行计划可开启新工作流；删除库中的定义不删除运行记录。

仅生成计划和 LLM 检查需要额外的 LLM API；目标与前序结果会发给该服务。Agent 使用各自登录或所选 API，LLM 不会自行检查文件或运行测试。工作流当前仅在本机执行，不含定时触发、任意条件分支和同项目并行写入。

## 权限与状态语义

- 内置 Agent 默认只读/计划模式；可明确选择允许修改项目。更宽权限需要手动选择，具体选项取决于 Agent。
- 需要原生交互审批时使用“交互终端”。无头模式的权限拒绝会显示等待操作；它不是原生权限审批的完整代理。
- 自定义命令模式通过参数数组启动，不解释 Shell 管道；`{prompt}` 和 `{project}` 为参数占位符。需要 Shell 语法时使用交互终端。自定义程序与终端沿用程序/系统权限，不受内置 Agent 的只读开关约束。
- “待启动”为手动队列，不会自动并发消费。内置任务“已完成”表示 CLI 正常退出且没有返回已知失败标记，不保证代码已通过人工验收。
- 导入的记录标为“历史会话”，不会通过文件修改时间推断外部 CLI 仍在运行或已成功完成。
- PTY 状态表示终端进程生命周期，不推断终端中每条命令的状态、审批或 Token；这类用量显示未上报。
- 统计曲线按会话最后活跃日期归组，不是逐请求的每日账单。缓存是输入的一部分，不重复加到总量；不猜测未上报 Token，也不按未知价格估算费用。
- 应用退出时停止它管理的运行进程。异常退出后，下次启动标记为中断，不自动重放任务。历史会话可继续，PTY 进程不跨应用重启保活。

## 数据与结构

macOS 默认数据目录：`~/Library/Application Support/com.oiagent.desktop/`。应用内“设置偏好”显示实际路径。

- `state.json`：项目、自定义 Agent、任务元数据、归档与重命名索引；通过临时文件与重命名保存。
- `logs/`：任务 JSONL 输出、归一化对话、PTY 原始字节记录。
- 历史源：`$CODEX_HOME/sessions` 和 `archived_sessions`（默认 `~/.codex`）、`$CLAUDE_CONFIG_DIR/projects`（默认 `~/.claude`）、`~/.qwen/projects`。
- 页面：`src/pages/`；组件：`src/components/`；跨端调用与类型：`src/lib/`。
- Rust：`discovery.rs`、`history.rs`、`runtime.rs`、`transcript.rs`、`terminal.rs`、`supervisor.rs`、`store.rs`。

当前没有提供自动跨设备历史同步、Git worktree 隔离、逐块接受/回退改动、自动定时任务、UI 插件沙箱和插件市场。扩展协议见 [插件文档](PLUGINS.md)，调研与后续设计见 [设计依据](RESEARCH.md)。

自动测试覆盖前端筛选、详情导航、历史归档恢复、启动入口、Token 去重和 CSV；后端覆盖三种历史解析、子会话关联、工具协议归一化、Gemini/OpenCode 流式事件与用量、增量缓存、真实子进程、退出失败、停止进程组、中文 PTY 输入、重启恢复，以及本地模拟 LLM 的完整编排。没有在测试中启动真实付费 Agent。自动化测试不包含桌面视觉验收；Windows 和 Linux 尚未实机验证。

## MCP 与 Skills

在「Agent 程序 → MCP 与 Skills」选择 Agent 和作用范围，也可从程序卡片直接进入。已适配 Codex、Claude Code、Qwen Code、Gemini CLI、OpenCode 的原生配置。支持 MCP 增删改、本地命令和远程服务表单、高级 JSON；Codex/OpenCode 还支持原生启停字段。

Skills 可从含 `SKILL.md` 的目录导入，也可新建、编辑和移除。导入保留附带资源，不执行脚本；移除将完整目录移到同级 `oiagent-skill-backups`。保存前检测外部修改并备份原文，下一次启动 Agent 时应用；项目配置的信任与工具授权仍由各 Agent 控制。共享的 `.agents/skills` 可能同时被多个 Agent 使用。

## 局域网连接

两台电脑均需安装 OiAgent：

1. 在执行任务的电脑打开「设置偏好 → 局域网连接」，填写名称，选择局域网地址、共享项目和 Agent。勾选允许执行任务后开启共享。
2. 生成配对码，在控制端同一页面点击「连接设备」并粘贴；回到执行端核对设备名称和 IP，允许配对。
3. 控制端「新建任务」选择执行设备和共享项目，启动任务。列表支持设备筛选，详情支持同步进展、追加消息、切换共享 Agent、停止与历史归档。

连接默认关闭，应用重启后需手动开启。使用 TLS 和配对证书校验；IP 或证书变更后需重新配对。令牌保存在系统凭据存储中，存储不可用时拒绝配对，不回退到明文。仅开放受限任务接口，不提供远程 TUI、文件编辑、API/MCP 管理或超级 Agent 调度。对话同步最近 4 MB，完整记录在执行端。

远程请求只能访问该设备自己创建的任务；任务目录必须是授权目录，不能提交任意启动参数或跳过全部权限检查。Agent 使用执行端账户和 API，可能修改文件并产生费用；授权目录不是 OS 沙箱。撤销授权或关闭共享立即拒绝新请求，已接受的任务继续运行，可在执行端停止。移除控制端连接会删除本机凭据，服务端授权需在执行端撤销。

证书握手及授权逻辑已通过本机自动化测试；两台物理设备联调、Windows/Linux 打包仍需在对应环境验证。

## 任务模板与 Prompt 优化

新建任务的输入框旁提供「任务模板」：按分类搜索、预览、新建或编辑模板，也能将当前输入保存为模板。`{{变量名}}` 会生成待填写项，填好后插入；已有内容默认保留并追加，也可明确选择替换。模板保存在应用数据目录的 `task-templates.json`，浏览器演示版使用独立的 localStorage。

魔法棒打开 Prompt 优化面板，可选择更清晰、更精简或结构化。使用「设置 → LLM API」中的 OpenAI 兼容 Chat Completions 配置，仅发送当前输入文本；不会读取项目文件或启动 Agent。建议可编辑，确认后替换，紧接着可撤销。如果等待期间修改了原文，需要重新优化。API Key 使用已保存的加密配置；本功能的用量不归到尚未创建的任务中。

从任务详情的「＋」、标签栏「＋」、侧边栏或 `Cmd/Ctrl+N` 新建任务，会沿用当前项目与 Agent；远程任务保留执行设备。项目右键菜单也能直接新建。新任务从空白内容和默认安全权限开始，原任务标签保留。正在查看本机文件时，以该文件的项目为准。

## GitHub 自动发布

推送版本 tag（如 `v0.1.0`）会自动构建 Windows、Linux，以及 macOS 的 Intel / Apple Silicon 安装包，全部成功后发布到 GitHub Releases。版本号取自 tag，预发布 tag 会标记为 Pre-release。配置、产物和签名说明见 [发布文档](RELEASING.md)。

## Skill 文件编辑

在「Agent 程序 → MCP 与 Skills → Skills」点击条目，会打开 `名称 / SKILL.md` 文件标签，使用 Monaco Markdown 编辑器。保存支持 `Cmd/Ctrl+S`，切换标签保留草稿，关闭未保存文件会提示；外部修改通过差异视图比较。保存仍校验 Skill 元数据、文件夹名称和版本，并备份原文。新建时填写名称与用途，然后进入文件标签编写内容。

## 使用系统程序打开文件

项目列表、项目文件树、文件标签的右键菜单提供「在系统文件管理器中显示」和「使用默认程序打开」；编辑器右上角「文件操作」提供相同入口。打开的是磁盘版本，未保存编辑仍留在 OiAgent。仅操作本机存在的普通文件和文件夹，不通过局域网 RPC 执行此操作。


## 临时项目

新建任务时选择「临时项目」，无需指定目录。OiAgent 会在应用数据目录的 `temporary-projects/` 下分配独立文件夹，适用于 Agent 对话、自定义命令、交互终端和自动派发。没有当前项目时默认选择临时项目；启动前不创建目录，失败重试复用当前草稿已分配的目录。

任务完成或关闭标签后保留文件。所有任务归档 7 天后，在下一次启动应用时清理；父任务归档覆盖已结束的内部子任务。恢复或继续会话会取消原清理期限。只分配了目录、未创建任务的项目保留 7 天。

进入项目后，上方提供「保留项目」和「清理临时文件」。保留后不再自动清理，目录位置和原生会话路径保持不变。手动清理会确认永久删除目录内容、归档任务并保留对话记录；运行中、待启动或仍有待发送消息的项目不能清理，打开的文件标签也必须先关闭。

清理仅接受 OiAgent 登记、路径匹配并具有归属标记的目录，不跟随符号链接删除外部文件。启动时先移入应用管理的 `temporary-trash/`，递归删除在后台执行；中断后下次启动重试。已清理的项目不再作为可用工作目录，历史仍可阅读。当前不通过局域网分配临时项目。

## 指令文件

「Agent 程序 → 指令文件」管理当前用户或指定项目的常用原生指令文件。Agent 卡片也提供入口。当前支持 Codex 的 `AGENTS.md` / `AGENTS.override.md`，Claude Code 的 `CLAUDE.md` 等，Qwen Code 的 `QWEN.md` 等，Gemini CLI 的 `GEMINI.md`，以及 OpenCode 的 `AGENTS.md`。

创建或编辑均打开 Monaco 文件标签，保存时才写入磁盘。支持未保存提示、外部修改比较、原文备份与 256 KB 文本限制。备份位于文件同目录的 `.oiagent-instruction-backups`。配置目录支持 `CODEX_HOME`、`CLAUDE_CONFIG_DIR` 和 `XDG_CONFIG_HOME`；不编辑符号链接。

页面展示当前范围的常用文件，不声称列出全部最终指令。父目录、子目录、导入文件、自定义文件名和兼容回退由原生 CLI 决定。保存后新会话按 CLI 规则读取，已有会话请自行重新加载或新开会话。OiAgent 不自动将本机指令加入 `.gitignore`。

## 关于页面

「设置偏好 → 关于」显示实际安装版本、系统和架构，可复制版本信息，并在系统浏览器中打开项目主页、版本记录、使用文档、问题反馈及图标许可说明。

## 网站与文档

项目首页与使用文档位于独立的 `website/`，使用 Astro + Starlight 生成静态页面，部署方式见 [网站说明](../website/README.md)。网站与桌面应用单独构建，不读取本机数据。

## 启动偏好与应用菜单

新建任务会记住上次选择的 Agent，以及每个 Agent 的执行权限；本机与各局域网设备分别保存。从任务内新建时优先沿用该任务的 Agent，权限仍使用该 Agent 的启动偏好。程序不可用或权限选项已变更时恢复可用的默认项。Prompt、启动参数和环境变量不会保存到启动偏好中。

桌面菜单提供文件、编辑、视图、窗口和帮助入口。「文件」可新建任务、添加项目、保存文件或关闭当前标签；「视图」可切换功能页面、搜索任务、收起侧栏或返回上一页。关闭标签不会停止任务，未保存文件仍需选择保存或放弃。macOS 的设置与关于位于 OiAgent 菜单，Windows / Linux 分别位于文件与帮助菜单。

常用快捷键：新建任务 `⌘/Ctrl+N`、添加项目 `⌘/Ctrl+O`、保存文件 `⌘/Ctrl+S`、关闭标签 `⌘/Ctrl+W`、搜索任务 `⌘/Ctrl+K`、显示或隐藏侧栏 `⌘/Ctrl+B`、设置 `⌘/Ctrl+,`。

## 背景与编辑器主题

在「设置偏好 → 界面设置」分别调整内容与对话、图标导航栏、侧边栏的背景色，可用颜色选择器或填写六位 HEX 色值。浅色和深色外观各自保存，切换外观后可配置另一套颜色。文字、悬停和选中态跟随背景调整；单项重置和「恢复默认背景」只影响当前明暗模式。

代码编辑器主题可跟随应用，也可固定为 Visual Studio 浅色、深色或高对比度浅色、深色。设置即时应用到 Monaco 文件编辑器与差异编辑器，包括 Skill 和指令文件；不影响 Agent TUI 自身主题。

## 计划颜色与拖动

计划列表和编辑页都可选择颜色标记，支持红、橙、黄、绿、蓝、紫及清除标记。颜色用于区分计划，不改变重要程度或截止日期。

选择「手动排序」后，按住计划左侧的拖动手柄：放在另一条计划的中间成为子计划，放在上、下边缘调整同级顺序，拖到底部「移为独立计划」区域可解除父子关系。放下前显示目标位置，整组子计划会一起移动。搜索或筛选期间不支持拖动；清除筛选后可继续。顺序和父子关系保存在本机，不允许循环或超过五层。

## 页面返回与固定标签

返回按钮位于顶部面包屑左侧，有上一页时显示。标签栏最左侧固定显示最近使用的功能页；打开任务或文件后，点击它可回到原来的列表或设置页。固定标签不会被关闭，也不参与「关闭其他标签」。标签栏支持左右方向键和 Home / End 切换。

对话的执行过程分组默认展开，命令等最底层执行项默认收起。「派发子 Agent」收到子消息或执行记录后仍保持收起，点击可查看完整内容。

## 置顶、颜色与归档整理

将鼠标移到左侧项目或会话列表上，可直接置顶、取消置顶和选择颜色。触屏上直接显示这些按钮，也可用 Tab 聚焦操作。左侧项目置顶后排在最前，其余项目仍按最近使用排序；项目不提供归档。会话右键菜单也提供置顶和归档入口。

会话可标记为红、橙、黄、绿、蓝、紫六种颜色。颜色只用于区分，不改变任务状态。置顶与颜色保存在本机，重启后保留。不同设备的同名项目分别保存标记。

在「历史记录 → 已归档」中，勾选会话后可批量恢复或删除。「全选」选择当前筛选结果，包括尚未滚动加载的记录；切换筛选条件会清空选择。

删除前会列出所选会话并要求确认。删除会移除所选会话及子任务在 OiAgent 中的记录和执行日志，关闭对应的任务标签。项目文件、已打开的文件标签和导入的原始 Agent 历史文件保留；被删除的会话不会在下次扫描时重新导入。仍有未结束子任务时不能删除；工作流中的子任务须随所属工作流记录一起删除。

局域网会话在执行设备上归档或删除，需要该设备在线且当前连接有操作权限。多个设备分别处理，一台设备失败不会撤销其他设备已完成的操作；失败的会话会保留选择，可重试。
