## 打开和编辑

进入项目或任务后，侧栏自动显示「文件」折叠区；项目列表仍可同时使用。点击文件会打开编辑标签，支持语法高亮、自动换行和 `⌘/Ctrl+S` 保存。对话中的文件修改卡片也能直接打开文件。

文本文件须为 UTF-8，大小不超过 2 MB。符号链接、二进制文件和 Git 内部文件不进入编辑器。目录按需读取，隐藏文件和常见构建目录默认收起。

## Agent 修改了正在编辑的文件

打开的文件会定期检查磁盘版本。没有本地编辑时自动刷新；存在未保存内容时，保留草稿并提示比较差异。保存前还会检查版本，避免覆盖其他程序刚写入的内容。

切换任务或标签不会丢弃草稿。关闭未保存文件时，需要选择保存或放弃。

## 查看 Agent 改动

点击对话中修改记录的「查看改动」，查看这一步涉及的文件。任务详情的「改动」页汇总整个会话；左侧选择文件，右侧查看差异。同一文件改过多次时，可以切换修改步骤。

这里使用 Agent 记录的原文、替换片段或补丁，不需要初始化 Git。支持新增、修改、删除和重命名；文本对比可切换统一视图或左右视图，补丁保留行号与分段。

未完成或失败的工具调用会标记为计划改动。记录没有原文时，只展示已记录的内容；不会用当前磁盘文件推测历史版本。命令行脚本、旧版 CLI 或被截断的记录可能没有完整差异。查看改动不会修改项目文件。

## 查看 Git 改动

侧栏「Git 改动」显示工作区相对最近提交的差异，包括暂存、未暂存和未跟踪文件。这是整个工作区的状态，不限定当前 Agent。

「本任务记录涉及」表示会话提到过这个文件，不能作为修改归属的证明。当前不提供逐块接受、回退或自动提交。

## 使用系统程序

文件、文件标签和项目目录的右键菜单提供：

- **在系统文件管理器中显示**：定位到 Finder、资源管理器或系统文件管理器。
- **使用默认程序打开**：使用系统关联的程序打开磁盘文件。

未保存的编辑不会自动写入磁盘。这些操作只适用于本机文件。
