## 打开和编辑

进入项目或任务后，在侧栏切换到「文件」。点击文件会打开编辑标签，支持语法高亮、自动换行和 `⌘/Ctrl+S` 保存。对话中的文件修改卡片也能直接打开文件。

文本文件须为 UTF-8，大小不超过 2 MB。符号链接、二进制文件和 Git 内部文件不进入编辑器。目录按需读取，隐藏文件和常见构建目录默认收起。

## Agent 修改了正在编辑的文件

打开的文件会定期检查磁盘版本。没有本地编辑时自动刷新；存在未保存内容时，保留草稿并提示比较差异。保存前还会检查版本，避免覆盖其他程序刚写入的内容。

切换任务或标签不会丢弃草稿。关闭未保存文件时，需要选择保存或放弃。

## 查看改动

「改动」展示整个工作区相对 Git HEAD 的差异，包括暂存、未暂存和未跟踪文件，不是当前 Agent 独占的改动。

执行记录涉及的文件可以标记为「本任务记录涉及」，但读取文件也可能产生这个标记。没有 Git 时仍能编辑文件，只是不提供历史版本。当前不提供逐块接受、回退或自动提交。

## 使用系统程序

文件、文件标签和项目目录的右键菜单提供：

- **在系统文件管理器中显示**：定位到 Finder、资源管理器或系统文件管理器。
- **使用默认程序打开**：使用系统关联的程序打开磁盘文件。

未保存的编辑不会自动写入磁盘。这些操作只适用于本机文件。
