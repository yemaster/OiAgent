## 新建任务

选择项目和 Agent，填写任务内容即可启动。没有项目目录时，可选择[临时项目](../temporary-projects/)。在项目或任务中点击「＋」，会沿用当前项目和 Agent，权限恢复为默认值。

「运行方式」提供 Agent 对话、自定义命令和交互终端。「更多设置」中可以填写任务名称、模型、额外参数和环境变量，也可以保存为待启动任务。

额外参数每行一个，通过参数数组传递，不解释 Shell 管道。环境变量每行 `NAME=value`，仅保留在本次应用内存中。

## TODO List

左侧清单图标打开计划列表。输入名称后按 Enter 添加；「添加详情」和点击计划名称都会打开独立编辑页，可填写备注、父计划和项目目录。返回列表保留草稿及筛选状态。列表支持搜索、按项目筛选、重要标记和颜色标记。颜色可在列表或编辑页选择，不改变重要程度。

在计划的「更多操作」中选择「添加子计划」，默认沿用父计划的项目目录。最多支持 5 层，列表可折叠并显示子计划完成数；编辑页可更换父计划或改为独立计划。

选择「手动排序」后，拖动左侧手柄：放在计划中间成为子计划，放在上下边缘调整同级顺序，拖到底部「移为独立计划」区域解除父子关系。移动父计划时会保留其子计划。搜索、项目筛选或重要筛选期间不能拖动，清除筛选后可继续。

勾选计划后移入「已完成」，取消勾选可恢复。完成父计划会一并完成所有子计划，未完成的子计划会在操作前提示确认。恢复子计划时也会恢复其上级计划。删除父计划会保留子计划并上移一级。

未完成计划右侧的「创建任务」会把名称、备注和目录填入新建任务页，父计划还会附带未完成子计划和备注，再由你选择 Agent 并启动。没有指定目录时使用临时项目。

已有任务草稿时，可以追加计划内容、替换草稿或取消。追加保留原草稿的项目和 Agent 设置。计划不会随任务启动或结束自动完成，确认结果后自行勾选。

计划保存在本机，重启后保留。删除计划不会删除已经创建的任务。

## 查看状态

| 状态 | 含义 |
| --- | --- |
| 待启动 | 已保存，尚未执行，需要手动启动。 |
| 进行中 | OiAgent 管理的执行进程正在运行。 |
| 等待操作 | 检测到权限拒绝或需要用户处理，查看详情或切换原生终端。 |
| 已完成 | CLI 正常退出，且未返回已知失败标记；结果仍需自行验收。 |
| 失败／已停止／已中断 | 执行出错、被停止，或应用重启前未确认完成。 |
| 历史会话 | 从本机日志导入，不据此推断外部 CLI 是否仍在运行。 |

## 追加消息

在任务底部输入后续要求。任务运行中发送的消息进入队列，本轮成功结束后依次执行；失败、停止或等待操作时暂停队列。未发送的消息可以撤回。

追加消息不是对 CLI 当前执行过程的即时指令。终端模式下请直接在终端输入。

## 管理历史

历史记录支持按项目搜索、重命名、归档、恢复和 Markdown 导出。归档和重命名只修改 OiAgent 的索引，不改写 Agent 原始日志。

标签保存任务的阅读位置和未发送内容。关闭标签不停止任务；退出应用会停止由 OiAgent 管理的进程。

## 置顶、颜色与归档整理

将鼠标移到左侧项目或会话列表上，可直接置顶、取消置顶和选择颜色。触屏上直接显示这些按钮，也可用 Tab 聚焦操作。左侧项目置顶后排在最前，其余项目仍按最近使用排序；项目不提供归档。会话右键菜单也提供置顶和归档入口。

会话可标记为红、橙、黄、绿、蓝、紫六种颜色。颜色只用于区分，不改变任务状态。置顶与颜色保存在本机，重启后保留。不同设备的同名项目分别保存标记。

「历史记录」和「已归档」是侧边栏中的两个独立页面。在「已归档」中，勾选会话后可批量恢复或删除。「全选」选择当前筛选结果，包括尚未滚动加载的记录；切换筛选条件会清空选择。

删除前会列出所选会话并要求确认。默认开启「保留项目文件」和「保留 Agent 原始历史」，仅移除所选会话及子任务在 OiAgent 中的记录和执行日志，关闭对应的任务标签。取消保留后会显示待删路径：项目选项会删除整个目录，原始历史选项仅删除已识别的会话 JSONL 文件；这些文件删除后无法在应用内恢复。

共享目录、仍有打开文件标签的项目、系统和应用数据目录、符号链接，以及被其他会话引用的历史文件不能连带删除。每次打开确认框都会重新开启保留选项。执行前再次核对文件范围，路径或文件发生变化时需要重新确认；文件删除失败会显示具体路径和原因，会话记录仍按已确认的操作删除。被删除的会话不会在下次扫描时重新导入。仍有未结束子任务时不能删除；工作流中的子任务须随所属工作流记录一起删除。

局域网会话在执行设备上归档或删除，需要该设备在线且当前连接有操作权限。远程操作只删除会话记录，项目文件和原始历史须在执行设备上处理。多个设备分别处理，一台设备失败不会撤销其他设备已完成的操作；失败的会话会保留选择，可重试。
