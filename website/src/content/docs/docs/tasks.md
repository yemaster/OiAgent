## 新建任务

在页面底部输入任务内容，按 `⌘/Ctrl+Enter` 创建并启动任务；`Shift+Enter` 换行。发送和换行快捷键可在设置中修改，与任务对话共用。输入框左下方选择 Agent，右下方选择模型并发送。项目、权限和监管位于输入框下方；点击左侧「＋」打开任务工具。没有项目目录时，可选择[临时项目](../temporary-projects/)。在项目或任务中点击「＋」，会沿用当前项目和 Agent，权限使用该 Agent 上次保存的启动偏好。

任务工具中可切换 Agent 对话、自定义命令或交互终端，也可开启临时对话。输入框底部选择模型；Claude Code 选择 API 配置。「更多设置」中可以填写任务名称、额外参数和环境变量，也可以保存为待启动任务。

额外参数每行一个，通过参数数组传递，不解释 Shell 管道。环境变量每行 `NAME=value`，仅保留在本次应用内存中。

## 图片与文件

点击输入框的回形针添加附件，也可粘贴图片，或把文件拖到输入框。拖入文件夹仍用于打开项目。图片可点击预览，其他文件可在系统文件夹中查看。只添加附件、不填写文字也能发送。

附件随消息排队；移回输入框时同时恢复文字和附件。启动失败重试、重新打开会话和编辑消息分支会保留附件。应用保存文件副本，之后移动或修改原文件不影响已发送的内容。

| Agent | 图片 | 其他文件 |
| --- | --- | --- |
| Codex | 原生 `--image`，包括 `exec resume` | 文件引用，由 Agent 读取 |
| Claude Code / Qoder CN | `stream-json` 图片内容块 | 文件引用，由 Agent 读取 |
| OpenCode | 原生 `--file` | 原生 `--file` |
| Aider | 原生 `--read` | 文本使用 `--read`，二进制文件使用文件引用 |
| Gemini / Qwen Code | 文件引用，单独加入附件目录 | 文件引用，单独加入附件目录 |
| Goose / 自定义 Agent | 文件引用 | 文件引用 |

图片是否能被理解取决于所选模型及 Agent 的读取能力；文件引用不等于把文件内容直接上传给模型，可能需要授权读取。Qwen 的 SDK 输入类型未声明图片块，OiAgent 不向其发送其他 Agent 的图片协议。实现依据：[Codex CLI](https://learn.chatgpt.com/docs/developer-commands?surface=cli)、[Claude 流式输入](https://code.claude.com/docs/en/agent-sdk/streaming-vs-single-mode)、[Qoder SDK](https://docs.qoder.com/cli/sdk/references-typescript)、[OpenCode CLI](https://dev.opencode.ai/docs/cli)、[Aider](https://aider.chat/docs/config/options.html)、[Gemini 文件工具](https://geminicli.com/docs/tools/file-system/)、[Qwen 配置](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/settings/)。

每条消息最多 10 个附件、合计 20 MB；单张图片不超过 5 MB。原生图片支持 PNG、JPEG、GIF、WebP；其他格式按普通文件传入。局域网远程任务、超级 Agent 和交互终端暂不提供附件传输，不会把本机路径误传为远端文件。附件保存在应用数据目录，不会写入项目目录。

复制对话内容会保留 Markdown 格式，粘贴富文本会转换为 Markdown。用户消息中的换行会直接显示，列表、加粗和代码块继续按 Markdown 渲染。

## TODO List

左侧清单图标打开计划列表。输入名称后按 Enter 添加；「添加详情」和点击计划名称都会打开独立编辑页，可填写备注、父计划和项目目录。返回列表保留草稿及筛选状态。列表支持搜索、按项目筛选、重要标记和颜色标记。颜色可在列表或编辑页选择，不改变重要程度。

计划可设置截止日期，也可用「今天」「明天」快速填写；列表标出今天到期和逾期计划。按截止日期排序时，无日期的排在后面，日期相同则重要计划优先。

在计划的「更多操作」中选择「添加子计划」，默认沿用父计划的项目目录。最多支持 5 层，列表可折叠并显示子计划完成数；编辑页可更换父计划或改为独立计划。

选择「手动排序」后，拖动左侧手柄：放在计划中间成为子计划，放在上下边缘调整同级顺序，拖到底部「移为独立计划」区域解除父子关系。移动父计划时会保留其子计划。搜索、项目筛选或重要筛选期间不能拖动，清除筛选后可继续。

勾选计划后移入「已完成」，取消勾选可恢复。完成父计划会一并完成所有子计划，未完成的子计划会在操作前提示确认。恢复子计划时也会恢复其上级计划。完成全部子计划不会自动完成父计划，仍需手动确认。删除父计划会保留子计划并上移一级。

未完成计划右侧的「创建任务」会把名称、备注、截止日期和目录填入新建任务页，父计划还会附带未完成子计划和备注，再由你选择 Agent 并启动。没有指定目录时使用临时项目。

已有任务草稿时，可以追加计划内容、替换草稿或取消。追加保留原草稿的项目和 Agent 设置。计划不会随任务启动或结束自动完成，确认结果后自行勾选。

计划保存在本机，重启后保留。删除计划不会删除已经创建的任务。

## 进程和服务、产物

点击对话右上角的 **日志** 图标，打开任务概览。概览显示 Git 改动、会话资源、任务目标和 Agent 提供的计划；点击文件可查看 Git 差异。

在概览的「会话」中，点击 **进程和服务 / 产物** 打开对应详情。入口显示数量和未读标记，打开对应面板后清除；切换任务或重启应用会保留已读状态。

- **正在运行**：在「进程和服务」中显示当前仍在执行的命令和进程，结束后自动移除。展开可查看完整命令与输出。
- **服务**：显示启动日志中报告的 Host 和端口。后台命令通过 `PORT=8080`、`--port` 等指定端口但没有打印地址时，会检测本机端口，可连接后显示并提醒。检测只在当前任务页面进行；不会扫描端口范围或检测远程设备。端口连通不代表进程归属，历史启动记录也不代表服务仍在运行。
- **产物**：左侧选择文件，右侧预览正文。

Agent 成功创建、修改的文件会自动加入产物列表，不需要在回复中再次列出文件名。已删除的文件不显示。通过命令生成的文件，需要在「最终产物」段落中提交，且修改时间位于任务执行期间。文件可预览、在编辑器中打开，或使用系统程序打开。支持普通任务和导入的本机会话，临时项目也可以使用。

文件按需读取，不扫描整个项目。写入记录按日志增量索引，长对话中较早的修改也会保留。列表最多显示 1000 个文件；文本预览最多读取 256 KB。工具读取过的文件不会仅因出现在执行记录中就加入产物；文件删除后刷新列表即可移除。

## 查看状态

| 状态 | 含义 |
| --- | --- |
| 待启动 | 已保存，尚未执行，需要手动启动。 |
| 进行中 | OiAgent 管理的执行进程正在运行。 |
| 等待操作 | Agent 请求审批或回答问题，或因权限被拒绝而暂停。打开详情处理。 |
| 已完成 | CLI 正常退出，且未返回已知失败标记；结果仍需自行验收。 |
| 失败／已停止／已中断 | 执行出错、被停止，或应用重启前未确认完成。 |
| 历史会话 | 从本机日志导入，不据此推断外部 CLI 是否仍在运行。 |

## 审批与提问

OiAgent 启动的 Claude Code 和 Qwen Code 对话任务支持在会话中处理审批。需要使用支持 SDK 控制协议的 CLI 版本；是否弹出审批由所选执行权限和 Agent 自身规则决定。

- **执行命令**：显示完整命令及工作目录，选择「允许本次」或「拒绝」。
- **修改文件**：显示文件路径和修改内容，展开「全部操作参数」可核对完整请求。
- **回答问题**：选择 Agent 给出的选项，或填写其他回答；所有问题填写后才能提交。
- **拒绝或停止**：拒绝会把原因返回 Agent，让它调整方案；「停止任务」会结束整个任务。

审批仅对当前请求有效，不会更改后续任务权限。Agent 撤回请求、任务停止或应用重启后，旧按钮不再有效。工作流子任务等待审批时保留执行进程，可打开子任务处理后继续。

Codex exec 及其他尚未接入双向审批协议的程序，在详情中提供阻塞信息和原生终端入口。导入的历史记录不能回复审批；局域网任务目前需要在执行设备上处理。切换终端可能需要停止当前执行，进入前会显示对应操作。

## 上下文整理

Agent 压缩上下文时，对话中显示「正在整理上下文」和循环进度条，完成后显示「上下文已整理」。停止或失败时结束动画；没有百分比数据时不显示百分比。

该提示依赖 Agent 发出的事件。Claude Code、Qoder CN 的 SDK 状态与完成事件可被识别；Codex 当前的 `exec --json` 通道不提供压缩开始事件，读取原生历史中的压缩完成记录时才显示结果。不同 CLI 版本的可用事件可能不同。

## 追加消息

在任务底部输入后续要求。运行时默认排队，当前轮成功结束后依次执行。发送按钮旁的菜单提供「立即发送」：停止当前执行，再携带会话上下文接续这条消息，其他排队消息保留。

「停止」结束当前执行并暂停队列。停止后输入新消息会直接启动新一轮，旧队列保留。每条待发送消息都可选择「立即发送」，或点击叉号移回输入框编辑。已有草稿会保留在其后；已经发送的消息不能撤回到队列。「继续队列」按原顺序执行。

消息按 Agent 的实际接入通道发送。当前 Codex 使用 `exec` 单轮通道，默认在本轮结束后续接；Claude Code、Qwen Code 和 Qoder CN 的默认队列也在本轮结束后续接，等待审批时不会擅自批准工具。更换 Agent、API 配置或模型参数会在该条消息执行时应用。强制发送先停止旧进程、清理审批通道，再恢复会话，不向不支持的通道发送交互指令。

输入框下方选择 Agent、模型和执行权限。Claude Code 的模型入口替换为 API 配置选择。运行时可停止任务，等待审批时可直接进入处理。发送按钮的悬停提示显示当前快捷键。

点击对话中的网页链接后，先确认目标网址，再使用系统浏览器打开。开启“下次不再提示”并确认打开后，后续网页链接会直接打开；可在 **设置 → 通用设置 → 打开外部链接前确认** 中恢复提示。项目内的文件链接、行内代码形式的文件路径可直接打开编辑器；`:12:3`、`#L12` 等引用会定位到指定行列。已打开的文件复用原标签，保留未保存的内容。远程任务的文件不会映射到本机目录。

对话中的项目图片显示为缩略图；点击图片、图片链接或文件列表中的图片，先打开预览弹窗。需要独立标签页时，点击“在编辑器中打开”。外部图片需点击“加载外部图片”。

图片右键菜单提供“复制图片”，复制图片内容而非路径。支持 PNG、JPEG、GIF、WebP、BMP、ICO 和 SVG 预览，可缩放或适应窗口；SVG 可切换到源码编辑。图片超过 20 MB、尺寸过大或格式不支持时，可使用系统程序打开。外部图片复制受来源网站的跨域许可限制。

文件修改卡片提供“打开文件”和“查看改动”。无法预览的二进制文件仍可在系统文件管理器中显示，或使用默认程序打开。

Agent 注入的环境信息和项目指令不作为用户消息显示；原始日志保留，代码块中引用的示例不受影响。

Claude Code 和 Qwen Code 的本机对话任务支持运行中切换权限；收到 Agent 确认后更新当前模式，不支持或切换失败会保留原值。切换不代替对已有审批的答复。其他 Agent、远程任务及切换 Agent 时，权限用于下轮执行。

「立即发送」通过停止并恢复会话实现，不是向正在执行的工具注入消息。终端模式下请直接在终端输入。

回复中的代码、执行命令和审批中的文件内容支持高亮与复制。长代码可滚动；未标明语言、未支持的语言和超长内容按原文显示。

## 管理历史

历史记录支持按项目搜索、重命名、归档、恢复和 Markdown 导出。归档和重命名只修改 OiAgent 的索引，不改写 Agent 原始日志。

标签保存任务的阅读位置和未发送内容。关闭标签不停止任务；退出应用会停止由 OiAgent 管理的进程。

## 置顶、颜色与归档整理

将鼠标移到左侧项目或会话列表上，可直接置顶、取消置顶和选择颜色。触屏上直接显示这些按钮，也可用 Tab 聚焦操作。左侧项目置顶后排在最前，其余项目仍按最近使用排序；项目不提供归档。会话右键菜单也提供置顶和归档入口。

会话可标记为红、橙、黄、绿、蓝、紫六种颜色。颜色只用于区分，不改变任务状态。置顶与颜色保存在本机，重启后保留。不同设备的同名项目分别保存标记。

「历史记录」和「已归档」是侧边栏中的两个独立页面。在「已归档」中，勾选会话后可批量恢复或删除。「全选」选择当前筛选结果，包括尚未滚动加载的记录；切换筛选条件会清空选择。

删除前会列出所选会话并要求确认。默认开启「保留项目文件」和「保留 Agent 原始历史」，仅移除所选会话及子任务在 OiAgent 中的记录和执行日志，关闭对应的任务标签。取消保留后会显示待删路径：项目选项会删除整个目录，原始历史选项仅删除已识别的会话 JSONL 文件；这些文件删除后无法在应用内恢复。

共享目录、仍有打开文件标签的项目、系统和应用数据目录、符号链接，以及被其他会话引用的历史文件不能连带删除。每次打开确认框都会重新开启保留选项。执行前再次核对文件范围，路径或文件发生变化时需要重新确认；文件删除失败会显示具体路径和原因，会话记录仍按已确认的操作删除。被删除的会话不会在下次扫描时重新导入。仍有未结束子任务时不能删除；工作流中的子任务须随所属工作流记录一起删除。

局域网会话在执行设备上归档或删除，需要该设备在线且当前连接有操作权限。远程操作只删除会话记录，项目文件和原始历史须在执行设备上处理。多个设备分别处理，一台设备失败不会撤销其他设备已完成的操作；失败的会话会保留选择，可重试。

## 模型配置

点击输入框底部的模型名称，选择模型并调整它支持的思考深度、速度或上下文窗口。新建任务时，模板和 Prompt 优化位于左下角「＋」菜单。

- **Claude Code**：选择已有 API 配置，或沿用本机配置。配置在「Agent 程序 → Claude Code API 配置」中管理。
- **Codex**：从当前 CLI 获取模型、推理档位和速度选项，支持时显示 Fast。
- **Qoder CN**：从 SDK 获取账号可用模型，以及各模型的思考深度和上下文窗口。Fast 路由按 CLI 返回的模型项显示。
- **Qwen Code、OpenCode**：读取 CLI 提供的模型列表；不提供列表的程序可以手动填写模型 ID。

模型列表可手动刷新。没有返回的能力不会显示为可选设置。局域网任务沿用目标设备的配置，仅支持填写模型名称。

排队消息保留提交时选择的模型参数。思考深度、速度和上下文窗口在下一轮启动时应用；正在运行的 Claude Code、Qwen Code 和 Qoder CN 切换具体模型时，使用原生控制接口，收到确认后生效。

## 运行状态与后台通知

- **等待操作**：Agent 有尚未回复的审批或输入请求。已拒绝、撤回或过期的请求不能再次批准。
- **终止中**：停止请求已提交，正在等待进程退出和输出清理。此时不会启动同一会话的新进程。
- **终端运行中**：会话已交给原生 TUI。终端退出后，会话同步为完成、失败或已停止。

Claude Code、Qwen Code、Qoder CN 的交互通道会跟踪原生后台任务事件。有后台任务时保留连接，完成通知由 Agent 自行处理；不会把通知伪造成用户指令。Qoder Monitor 的中间通知不等于 Monitor 已结束。长期监听任务需手动停止。

权限拒绝记录只表示之前的工具没有获准，不代表现在有审批可回复。执行结束后仍存在未处理的拒绝时，任务标记为已中断，可调整权限后追加要求，或进入原生终端。OiAgent 不自动重试被拒绝的操作。

各 Agent 的接入能力不同：

| Agent | 当前接入 | 审批与交互 |
| --- | --- | --- |
| Claude Code / Qwen Code / Qoder CN | 双向 stream-json | 显示真实工具审批、问题选项；处理请求撤回和结束清理 |
| Codex | `exec --json` | 保留单轮执行语义；需要原生交互时进入 TUI |
| Gemini CLI | headless stream-json | 权限策略拒绝作为结果记录，不显示虚假的待审批按钮 |
| 其他 Agent / 自定义程序 | 对应 CLI 或终端 | 仅使用已接入的协议；交互操作在原生终端处理 |

协议依据：[Claude streaming input](https://code.claude.com/docs/en/agent-sdk/streaming-vs-single-mode)、[Qoder SDK](https://docs.qoder.cn/en/cli/sdk/references-typescript)、[Qwen SDK](https://qwenlm.github.io/qwen-code-docs/en/developers/sdk-typescript/)、[Codex App Server](https://developers.openai.com/codex/app-server/)、[Gemini 权限策略](https://geminicli.com/docs/reference/policy-engine/)。Codex App Server 的双向审批与 `exec` 是不同接口，当前不会混用。

## 定位与编辑消息

对话右侧的刻度可跳转到用户消息，悬停查看摘要；聚焦刻度后用方向键逐条移动，Home / End 跳到首尾。向上滚动到顶部会自动载入更早内容，点击“回到最新”返回末尾。

停止任务及关联终端后，将鼠标移到用户消息上，点击编辑图标，原消息会变成输入框。修改后点击“保存并发送”；点击“取消”或按 Esc 恢复原消息。分支选择在输入框下方，文件恢复选项默认收起。

- **新建分支**：保留原会话，创建一条包含此前记录的新会话。
- **替换当前对话**：打开编辑后的会话，原会话移入“已归档”，仍可恢复。
- **撤销此处之后的文件修改**：开启后查看待恢复文件，确认后保存并发送。当前内容会备份到应用数据目录的 `rewind-backups`。

编辑后的消息在新的原生会话中执行，只携带编辑位置之前的文本与执行记录，不沿用包含后续消息的原生会话。上下文超过安全传递长度时会拒绝提交，不静默截断。当前不提供远程会话、子任务、终端或工作流本身的消息编辑。

文件恢复使用 Claude Code / Qoder CN 的原生检查点，需要明确的消息 UUID、会话和文件列表。Claude Code 要求 2.1.216 或更新版本；Qoder CN 的文件恢复目前限 macOS / Linux。其他版本、Agent 或没有检查点的历史消息会显示不可用原因。它不等同于撤销整个项目：Shell、外部服务和未被检查点记录的改动不会恢复。恢复前需保存编辑器中的文件并停止同项目任务；预览后文件发生变化会拒绝执行。恢复失败或结果未确认时不会启动新任务，也不会自动重复恢复。

协议参考：[Claude 文件检查点](https://code.claude.com/docs/en/agent-sdk/file-checkpointing)、[Qoder 文件检查点](https://docs.qoder.com/cli/sdk/checkpoint)。

## 恢复标签页

退出后再次打开，会恢复任务、文件和插件标签的顺序、选中项、分栏与分栏尺寸。文件重新从磁盘读取；插件仍需处于启用状态。临时对话不会恢复，任务和终端也不会自动运行。

## 自动任务标题

在 **设置 → 通用设置 → 任务标题** 选择：

| 模式 | 行为 |
| --- | --- |
| 不总结标题 | 保留原命名方式 |
| 仅首次总结 | 第一次启动时，根据任务要求生成短标题 |
| 每次总结 | 首次启动及后续消息提交时，根据原目标和最新要求更新标题 |

默认仅首次总结，使用“AI 服务”中选择的 API 或 Agent。生成在后台进行；未配置服务或调用失败时保留原标题。手动命名的任务、工作流步骤与终端不自动改名。连续追加消息时只采用最新一轮结果。

## 项目终端

打开项目后，点击底部状态栏的「终端」，或按 `Ctrl+\`` 显示底部终端。终端从项目目录启动，可拖动上边缘调整高度。快捷键可在设置中修改。

点击「＋」新建独立终端组，点击拆分按钮在当前组中添加窗格，拖动分隔线调整宽度。点击标签切换整组终端，分栏布局会保留。「取消终端分组」将窗格分别放到独立标签中。

收起面板不停止进程；垃圾桶终止当前聚焦的终端。确认进程退出后，自动移除对应窗格；组内所有终端退出后，关闭该组标签。切换项目后，各项目的终端分别保留。项目终端不会接管 Agent 对话；操作 Agent TUI 仍使用任务中的终端模式。直接退出会停止本次应用启动的 Agent、终端及其后台子进程，确认进程退出后才关闭应用；停止失败时可重试。最小化到托盘会继续运行任务。

对话中的网络重试仅实时显示，恢复输出后消失，不写入运行记录。模型提示直接显示在对话中，工具执行仍按原来的分组查看。


## 任务监管

在新建任务输入框旁选择「监管」，普通任务的输入框旁也可切换档位。

| 档位 | 行为 |
| --- | --- |
| 关闭 | 由你审批和继续任务 |
| 谨慎接管 | 检查结果、续办未完成工作；不确定时等待你 |
| 自动接管 | 处理任务范围内的常规审批和问题，并检查、修补遗漏 |

监管使用 **设置 → AI 服务** 中选择的 API 或已安装 Agent。自动续办默认最多 2 次，可设置为 1–5 次。检查会读取本轮执行记录及已验证产物的正文摘要；原 Agent 进程仍在运行时不会另起一轮。停止任务或关闭监管后，旧检查结果不再续办任务。

监管不会提高任务权限，也不会替你填写缺失的密钥。原生 Agent 未提供可回复的审批接口时，仍需在终端处理。
