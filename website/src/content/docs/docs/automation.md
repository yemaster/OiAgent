## 任务模板

在新建任务输入框旁打开「任务模板」。模板可以分类、搜索、预览、编辑，也可以将当前输入保存为新模板。

模板中的 `{{变量名}}` 会生成填写项。例如：

```text
检查 {{模块}} 的错误处理，重点关注 {{场景}}。
先说明发现的问题，再修改代码并运行相关测试。
```

插入时默认追加到已有内容，选择替换才会覆盖。模板保存在本机的 `task-templates.json`。

## Prompt 优化

点击输入框旁的魔法棒，选择更清晰、更精简或结构化。此功能需要先配置 [LLM API](../api/)。

只发送当前输入文本，不读取项目文件、不启动 Agent。建议可以继续编辑，确认后替换原文，紧接着可以撤销。等待期间修改了原文，需要重新优化。

## 超级 Agent

1. 在「设置偏好 → LLM API」保存服务地址、模型和密钥。
2. 打开「自动化」，选择项目或临时项目，填写目标。
3. 设置权限和最多子任务数，然后启动。
4. 查看生成的计划，打开各子任务检查执行记录与复核结果。

子任务按顺序执行，最多 8 个，每个限时 30 分钟。失败或权限阻塞会暂停派发，可以停止整个任务。LLM 的检查依据是子任务记录，不能代替人工验收。

目标和子任务输出会发送到你配置的 LLM，执行任务的 CLI 则使用各自的登录与 API 配置。
