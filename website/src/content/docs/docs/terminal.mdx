## 什么时候使用终端

需要回答 CLI 的交互问题、确认工具权限或使用程序自己的快捷键时，在任务详情中切换到 **终端**。也可以在新建任务的「运行方式」中选择交互终端，自行输入命令。

终端使用真实系统 PTY。它只替换对话区域，项目侧栏和标签栏保持可用；键盘、鼠标和滚动由终端及 Agent TUI 处理。

## 中途审批

<Aside type="caution" title="审批支持范围">
OiAgent 当前能显示「等待操作」，尚未提供统一的 GUI「允许／拒绝」审批卡片。需要审批时，请使用 Agent 原生 TUI。
</Aside>

切换 TUI 不会直接附着到已有无头进程。应用会先停止当前执行，再在新的终端中恢复原生会话；没有会话 ID 时打开新会话。因此，原先的待审批调用不保证原样保留，需要按 CLI 的提示继续。

如果任务只是因为只读或计划模式不能修改文件，可以确认所需权限后，新建任务或调整下一轮权限。

## 对话同步

已绑定原生会话的 Codex、Claude Code、Qwen Code 会从原生日志增量同步消息和工具事件。延迟取决于 CLI 写日志的时间，切换视图也会触发读取。

没有会话 ID 的终端，以及其他尚未适配历史格式的 Agent，只保留终端记录。PTY 状态表示终端进程的生命周期，不表示其中每条命令都已完成，也不据此估算 Token。

## 停止与退出

终端运行期间，聊天消息队列暂停。停止终端后可以回到对话模式继续。终端进程不会跨应用重启保活。
