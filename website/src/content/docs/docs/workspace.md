## 功能入口

- **工作台**：当前任务、历史记录、用量统计。侧栏项目按最近使用排序并跨启动记忆；没有使用记录的项目按最近任务时间排序。当前任务按等待操作、进行中、待启动分组，默认使用列表，可切换卡片。历史记录单独查看。
- **TODO List**：记录未完成和已完成的计划，按项目搜索、标记重要；将计划内容填入新建任务。
- **自动化**：超级 Agent 的自动派发。先连接 LLM API，再填写最终目标。
- **项目文件**：侧栏使用独立的「项目」「文件」「改动」折叠分区。进入项目或任务后自动显示文件区，项目列表仍可同时使用；点击分区标题展开或收起。折叠后停止该分区的后台刷新。按目录展开、搜索文件；点击文件在新 tab 中用 Monaco 编辑，`⌘/Ctrl+S` 保存。Git 改动以只读差异展示，可切换左右/统一视图。
- **Agent 程序**：显示已安装程序，未安装的收起；Claude Code API 配置为独立侧栏页面，Claude Code 卡片提供直达入口。
- **插件**：安装和管理应用插件，打开插件页面、调整设置与权限。
- **设置偏好**：通过侧栏切换通用设置、界面设置、快捷键、LLM API、局域网连接、关于等独立页面；API 草稿在切换时保留，新建任务可直达 LLM API 并返回草稿。左侧图标提示统一向右展开。
- **使用指南**：从应用菜单或托盘的「帮助」菜单打开。启动时有未结束任务就进入「当前任务」，否则进入「新建任务」。后台刷新不会切换正在使用的页面。

“新建任务”默认使用 Agent 对话；输入框旁的“运行方式”可切换自定义命令或交互终端。模型和 Claude Code API 配置在输入框底部选择。“更多设置”包含任务名称、额外启动参数（每行一个参数）和环境变量（每行 `NAME=value`）。从管理程序返回保留新建任务草稿。

## 状态栏

底部的状态项可以点击：

- **本地连接**：查看可用 Agent 数量、数据目录，进入 Agent 管理或局域网设置。
- **活跃任务**：进入当前任务，取消项目筛选。
- **同步**：查看自动同步状态、目录读取提示或错误，也可重新同步。

## 项目与目录

也可以从系统文件管理器将一个文件夹拖入 OiAgent，直接进入该项目的新建任务页。已有标签和未发送的任务草稿保留；拖入的目录使用本机执行。

在新建任务输入框下方点击项目名称，可搜索最近项目、粘贴绝对路径或选择「打开文件夹」。不指定目录时选择「临时项目」。连接局域网设备后，列表只显示该设备提供的项目。

进入项目后，点击「项目设置」打开项目指令、MCP 与 Skills；配置页直接使用当前项目目录，顶部返回按钮回到项目。菜单也提供定位文件夹和复制路径。侧栏项目的右键菜单提供相同配置入口。进入项目后，功能页标签显示项目名称；点击标签上的关闭按钮（或按 `⌘/Ctrl+W`）退出项目，恢复全部任务。已打开的任务和文件保留。

## 侧栏与标签

任务以独立 tab 打开，保留对话滚动位置和未发送内容；标签显示 Agent 图标、标题和状态，关闭标签不停止任务。面包屑随当前标签显示项目和任务。执行分组和包含嵌套执行记录的上层默认展开；最低一级工具调用（包括命令、编辑、计划、派发子 Agent）默认收起，摘要保留状态，点击后查看内容并复制。

关闭当前标签返回最近访问且仍可用的标签或页面；例如从 Skills 列表打开编辑器，关闭后回到该列表，不会跳到更早打开的任务。MCP / Skills 和指令文件页面会保留 Agent、作用范围及所选分页。关闭后台标签不改变当前视图；取消关闭或保存失败时保留编辑器和草稿。任务、文件、项目和聊天消息提供对应右键菜单。标签支持关闭其他 / 右侧标签，未保存的文件逐个询问，取消会停止后续关闭。Monaco 保留编辑器菜单，终端鼠标仍交给 TUI；表单保留系统文本编辑菜单。聚焦操作项后也可用 Shift+F10 打开菜单。

侧栏在页面间保持相同宽度，拖动右边缘调整并记住；双击恢复 256 px，聚焦分隔线后可用左右键调整。左侧工具栏图标统一为 24 px，点击区域为 40 px。图标栏、侧栏与内容区域采用不同底色；当前导航项以背景、字重和侧边标记突出。管理页面只呈现各自功能，点击“工作台”恢复之前的项目或标签。中间侧栏顶部只显示当前分区标题，不重复显示品牌名称。

## 返回与排序

返回按钮位于顶部面包屑左侧，有上一页时显示。标签栏默认在最左侧显示最近使用的功能页；打开任务或文件后，点击它可回到原来的列表或设置页。页面、任务和文件标签均可拖动排序，靠近标签栏边缘时自动滚动，按 Escape 可取消拖动。普通功能页标签不能关闭；项目标签的关闭按钮用于退出项目。功能页标签均不参与批量关闭。

排序在本次工作区内保留，新打开的标签追加到末尾。「关闭右侧标签」按当前排列执行；调整顺序不会切换页面，也不改变关闭后的返回位置。聚焦标签后，使用左右方向键或 Home / End 切换，使用 Alt+Shift+左右方向键调整顺序。

## 分栏

拖动标签到内容区的左、右、上、下边缘，可创建分栏；放到另一栏的中间或标签栏，可移动到该栏。任务、文件、插件和功能页标签均支持。

- 拖动分隔线调整宽度或高度，聚焦后可用方向键调整。
- 标签右键菜单和标签栏的「分栏布局」按钮提供相同入口，也可合并所有分栏。
- 每栏保留自己的当前标签。关闭标签优先返回本栏最近访问的标签，空栏自动收起。
- 新标签在当前操作的栏中打开；已打开的标签切回其所在栏。侧栏导航始终打开功能页标签。

移动标签保留聊天草稿和文件内容，运行中的任务继续执行。关闭未保存文件仍会询问是否保存。

## 启动偏好与应用菜单

新建任务和续聊输入框会记住选中的 Agent、执行权限、Claude API 配置、模型、思考深度、Fast 和上下文窗口，按设备、Agent 分开保存。选择后即保存，无需先发送消息。新建任务恢复这些选择；已有对话优先使用自身配置，实时权限或模型切换成功后才记住结果。程序不可用、API 配置被删除或权限选项失效时恢复可用的默认项。Prompt、手填启动参数和环境变量不保存到启动偏好中。

窗口顶部空白区域可拖动，双击可缩放。macOS 保留系统红绿灯和菜单栏，标题栏中央显示 OiAgent；Windows / Linux 将「文件、编辑、视图、窗口、帮助」平铺在左上角，窗口按钮位于右上角。

桌面菜单提供文件、编辑、视图、窗口和帮助入口。「文件」可新建任务、添加项目、保存文件或关闭当前标签；「视图」可切换功能页面、搜索任务、收起侧栏或返回上一页。关闭标签不会停止任务，未保存文件仍需选择保存或放弃。macOS 的设置与关于位于 OiAgent 菜单，Windows / Linux 分别位于文件与帮助菜单。

默认快捷键：新建任务 `⌘/Ctrl+N`、添加项目 `⌘/Ctrl+O`、保存文件 `⌘/Ctrl+S`、关闭标签 `⌘/Ctrl+W`、搜索任务 `⌘/Ctrl+K`、显示或隐藏侧栏 `⌘/Ctrl+B`、设置 `⌘/Ctrl+,`。

「设置偏好 → 快捷键」按 Windows、Linux、macOS 分开保存，默认显示当前系统。点击快捷键后按下新组合即可修改，重复组合保留并标记冲突，`Esc` 取消录入。「恢复默认」只重置所选系统。升级前保存的快捷键沿用到当前系统。

## 外观与编辑器主题

在「设置偏好 → 界面设置」分别调整内容与对话、图标导航栏、侧边栏的背景色，可用颜色选择器或填写六位 HEX 色值。浅色和深色外观各自保存，切换外观后可配置另一套颜色。文字、悬停和选中态跟随背景调整；单项重置和「恢复默认背景」只影响当前明暗模式。

代码编辑器主题可跟随应用，也可固定为 Visual Studio 浅色、深色或高对比度浅色、深色。设置即时应用到 Monaco 文件编辑器与差异编辑器，包括 Skill 和指令文件；不影响 Agent TUI 自身主题。

## 关闭窗口与退出

桌面版关闭窗口时，可选择「最小化到托盘」「退出应用」或「取消」。托盘菜单提供「显示窗口」「新建任务」「当前任务」「历史记录」；「快捷入口」包含工作流、待办、用量统计和 Agent 程序，设置、帮助和退出单独分组。macOS 的图标位于菜单栏，点击打开菜单；Windows 左键点击显示窗口，右键打开菜单。系统不支持托盘时，不提供隐藏窗口的选项。

最小化到托盘会保留窗口、未保存文件和运行中的任务。退出会停止本机由 OiAgent 管理的任务及终端，不会停止其他设备上独立运行的任务。仍有本机任务运行时，确认按钮显示为「退出并停止任务」。文件未保存时，提示退出会丢弃修改；取消后可返回编辑器保存。

勾选「记住此选择」后，下次关闭使用相同方式。可在「设置偏好 → 通用设置 → 关闭窗口时」恢复「每次询问」。即使记住了退出方式，有任务运行或文件未保存时仍会确认。菜单和托盘中的「退出」不会被重定向为最小化。

## 布局参考

侧栏采用 [VS Code Explorer 的分区方式](https://code.visualstudio.com/docs/editing/getting-started/userinterface#_explorer-view)；任务输入与项目上下文的编排参考 Qoder 工作区，常用操作保留在输入框附近。

## 检查更新

在「设置偏好 → 关于」点击版本号旁的「检查更新」。有正式新版本时显示版本号，点击前往对应 GitHub Release 下载安装包；没有更新时显示「当前已经是最新版本」。

桌面版启动后会在后台检查，运行期间每 6 小时检查一次。发现更新后，左下角设置按钮和「关于」入口显示黄点。检查失败可手动重试；不自动下载或安装，不推送预发布版本。

终端默认跟随应用的浅色／深色主题及内容背景。在「设置偏好 → 界面 → 终端配色」可单独选择浅色、深色或 Nord；选择会保存在本机，修改时保留终端连接。Agent TUI 自己指定的文字、真彩色背景仍由该程序控制。
