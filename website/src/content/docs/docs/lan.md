---
title: 局域网连接
description: 从另一台 OiAgent 电脑启动和查看远程任务。
---

两台电脑都需要安装 OiAgent。执行任务的一端使用自己的 Agent、登录账户和文件目录。

## 配对设备

1. 在执行端打开「设置偏好 → 局域网连接」，填写设备名称，选择局域网地址。
2. 选择允许共享的项目和 Agent，勾选允许执行任务，再开启共享。
3. 生成配对码。在控制端同一页面点击「连接设备」，粘贴配对码。
4. 回到执行端核对设备名称和 IP，允许配对。
5. 在控制端新建任务，选择执行设备与共享项目。

任务列表可以按设备筛选。远程详情支持同步进展、追加消息、切换共享 Agent、停止和归档。

## 连接范围

共享默认关闭，应用重启后需手动开启。TLS 连接会校验证书，地址或证书变更后需重新配对；配对令牌保存于系统凭据库。

远程请求只能操作该控制端创建的任务，只能使用授权目录和 Agent，不能提交任意启动参数。授权目录不是操作系统沙箱。

当前不提供远程 TUI、文件编辑、API／MCP／指令文件管理、临时项目分配或超级 Agent 调度。对话同步最近 4 MB，完整记录保存在执行端。

## 断开与撤销

关闭共享或撤销授权后，新的请求会被拒绝。已经接受的任务继续运行，需要在执行端停止。

移除控制端连接会删除本机凭据，执行端的授权需要在执行端撤销。目前已验证本机 TLS 和授权逻辑，两台物理设备联调仍需验证。
