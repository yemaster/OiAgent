---
title: 临时项目
description: 不指定已有目录时启动任务，并按需保留或清理文件。
---

## 创建

在「新建任务」中选择 **临时项目**。没有当前项目时默认选择此项。启动时，OiAgent 会在应用数据目录下分配一个独立文件夹，Agent、命令任务和交互终端都在该目录中运行。

临时目录在应用管理的存储中，不依赖操作系统随时可能清空的临时目录。每个新临时项目有独立路径。任务创建失败后重试，会复用该草稿已经分配的目录。

侧栏统一显示为 **临时项目**，其中的任务仍使用各自原来的目录。临时项目不显示侧栏的文件和改动分区；最终输出可在任务的 **产物** 中查看。

## 临时对话

在新建任务输入框下方开启 **临时对话**。关闭该对话标签时，OiAgent 会停止任务，删除临时目录及应用内的对话记录和日志。切换页面或标签不会删除。退出应用也会清理；异常退出后会在下次启动时补清理。

需要保留的文件请先复制到其他目录。此功能不删除 Agent 自己保存的原始历史，也不影响服务商的记录；这些历史不会重新导入 OiAgent。

## 保留结果

进入临时项目后，点击面包屑旁的 **临时项目**，选择 **保留项目**。选择后目录转为长期保留，不再自动清理，现有任务和原生会话仍使用原路径。

保留不会移动目录。要将文件放入自己的代码目录，可以通过系统文件管理器复制，然后将目标目录添加为项目。

## 清理规则

| 情况 | 处理方式 |
| --- | --- |
| 任务结束或关闭标签 | 保留文件，可以继续任务。 |
| 项目仍有未归档任务 | 不自动清理。 |
| 所有任务已归档满 30 天 | 下次启动应用时清理文件，保留对话记录。 |
| 恢复任务或创建后续任务 | 取消原清理期限，之后重新归档时再计时。 |
| 只创建了目录，未成功创建任务 | 保留 30 天，之后启动时清理。 |
| 已选择「保留项目」 | 不再自动清理。 |

也可以点击 **清理临时文件**，确认后删除目录内容并归档相关任务。清理前需要结束运行中、待启动及待发送的任务，并关闭该项目的文件标签。

文件清理后，对话记录仍可阅读；继续工作需要新建任务并选择其他目录。当前仅支持本机临时项目，远程任务仍需选择执行端授权的共享目录。

## 存储空间

在 **设置偏好 → 存储空间** 查看本机应用数据的容量占比和分类大小。点击 **清理空间** 查看可清理项目，或点击某个分类进入管理列表。支持按名称或路径搜索、按大小或名称排序、选择本页项目，每次最多选择 100 项。

勾选后点击 **删除所选**，确认页会列出项目、大小、目录和删除影响。默认不选择任何项目；取消确认返回原列表，关闭管理窗口后清空选择。项目详情、统计范围和自动清理规则通过对应的信息按钮查看。

- 普通临时项目：删除文件并归档任务，保留对话记录。
- 临时对话：删除该对话的项目文件和 OiAgent 记录，不删除 Agent 原始历史。
- AI 辅助临时文件：只有归属明确、超过 24 小时且已不在使用的目录可以清理。旧版未带归属标记的目录保持保护。
- 运行中、排队中、有待发送消息、已保留或仍在文件编辑器/新建任务草稿中使用的项目不能清理。删除前会重新检查状态与文件版本；变化后需要重新分析并确认。

统计按应用数据目录内的文件大小计算，不包含安装包、外部项目、Agent 原始历史及链接目标。附件、设置、运行组件等仍在使用的数据受保护；普通会话记录通过页面中的 **管理归档记录** 进入原有归档管理。

从旧版升级时，尚未清理的普通临时项目原有 7 天期限会延长到 30 天，只迁移一次。到期清理仍在下次启动时执行；恢复任务会取消到期时间，重新归档后重新计时。
