---
title: 临时项目
description: 不指定已有目录时启动任务，并按需保留或清理文件。
---

## 创建

在「新建任务」中选择 **临时项目**。没有当前项目时默认选择此项。启动时，OiAgent 会在应用数据目录下分配一个独立文件夹，Agent、命令任务和交互终端都在该目录中运行。

临时目录在应用管理的存储中，不依赖操作系统随时可能清空的临时目录。每个新临时项目有独立路径。任务创建失败后重试，会复用该草稿已经分配的目录。

## 保留结果

进入临时项目后，工作区上方提供 **保留项目**。选择后目录转为长期保留，不再自动清理，现有任务和原生会话仍使用原路径。

保留不会移动目录。要将文件放入自己的代码目录，可以通过系统文件管理器复制，然后将目标目录添加为项目。

## 清理规则

| 情况 | 处理方式 |
| --- | --- |
| 任务结束或关闭标签 | 保留文件，可以继续任务。 |
| 项目仍有未归档任务 | 不自动清理。 |
| 所有任务已归档满 7 天 | 下次启动应用时清理文件，保留对话记录。 |
| 恢复任务或创建后续任务 | 取消原清理期限，之后重新归档时再计时。 |
| 只创建了目录，未成功创建任务 | 保留 7 天，之后启动时清理。 |
| 已选择「保留项目」 | 不再自动清理。 |

也可以点击 **清理临时文件**，确认后删除目录内容并归档相关任务。清理前需要结束运行中、待启动及待发送的任务，并关闭该项目的文件标签。

文件清理后，对话记录仍可阅读；继续工作需要新建任务并选择其他目录。当前仅支持本机临时项目，远程任务仍需选择执行端授权的共享目录。
